# Äquatormaßband × Titania Chaos

<AequatorHero lang="de" />

## Wie es entsteht

Menschen bringen textile Materialien und die darin wohnenden Geschichten. Die Beiträge
werden gehört, dokumentiert, vermessen, fotografiert, miteinander verbunden und auf
Kabelrollen aufgewickelt. So entsteht ein wachsendes analoges Archiv der
Menschheitsgeschichte, dessen gedachte Länge dem Erdäquator entspricht.
