# Guide

Welcome to the guide! This page contains helpful information about your project.

## Installation

To get started with development:

```bash
npm install
npm run docs:dev
```

## Development

Run the development server to preview your documentation locally:

```bash
npm run docs:dev
```

Visit `http://localhost:5173` in your browser to see the documentation site.

## Building

To build the documentation for production:

```bash
npm run docs:build
```

The built site will be in the `docs/.vitepress/dist` directory.

## Preview

To preview the built documentation:

```bash
npm run docs:preview
```
